# Demo pen

A **sample** PigPen session that the Pen replay plays back: two people (a designer in Claude Code,
an engineer in Cursor) adding a password-reset flow, with two handoffs between their agents.

The events are illustrative, not a real recording. Replace this folder with a real `.pigpen/`
from one of your own sessions (minus `private/`) before you share the demo widely, and say in the
README which one people are looking at.
